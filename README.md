# 🧠 Simon Game

A fun and interactive memory game inspired by the classic Simon electronic game. Watch the sequence of colors, repeat it correctly, and see how far your memory can take you! 🎮

## ✨ Features

🔴🟡🟢🔵 Color sequence generation  
🎯 Progressive difficulty with each level  
🎵 Sound effects and button animations  
⌨️ Start game with a key press  
❌ Game-over detection and restart functionality  
⚡ Fast and responsive gameplay

## 🛠️ Built With

- HTML5 🌐
- CSS3 🎨
- JavaScript ⚙️
- jQuery 💛

## 🎮 How to Play

1. Press any key to start.
2. Watch the highlighted color sequence.
3. Repeat the sequence by clicking the buttons.
4. A new color is added every level.
5. Keep going until you make a mistake!

## 🚀 Goal

Challenge your memory, improve your focus, and beat your highest score. 🏆
